# Contributing

Thanks for helping improve `mcp-catalog-snapshot`.

1. Open an issue for behavior changes or new public API.
2. Fork the repository and create a focused branch.
3. Run `npm ci` and `npm run check` on Node.js 18 or newer.
4. Add tests for normal, boundary, malformed-server, and abort behavior.
5. Update the README and changelog when behavior changes.
6. Submit a pull request explaining the problem, design, and compatibility impact.

Contributions must be original or appropriately licensed. By submitting a contribution, you agree it may be distributed under this project's MIT license.
